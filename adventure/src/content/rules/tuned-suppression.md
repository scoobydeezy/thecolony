A tuned suppression lattice is an EGRESS device calibrated to a **known Incursion signature**. It suppresses reconstruction; it does not Stabilize, Anchor, or remove mnemonic Weight.

* The lattice can be calibrated only after EGRESS has observed enough of a specific Incursion to identify the reconstruction/resonance signature it is suppressing.
* It is normally applied while that Incursion is **Dispersed**.
* While the Source remains inside a powered, correctly tuned lattice, the specified Incursion does not reconstruct and **Reconstruction Pressure does not accumulate** for that suppressed signature.
* Ending suppression while the relevant Reconstruction Condition is true begins a normal Stabilization Window at 0 Pressure.
* Suppression is **signature-specific**. A different Incursion produced by the same Source—especially one using a different Resonance profile—is not automatically suppressed.
* Suppression never changes Source Level, Class, restored Identity, Capacity requirements, or the ultimate need for Resolution.

See :ref[Containment]{#encounter.containment} for the portable lattice’s particular signature and its limitations in that scene.
