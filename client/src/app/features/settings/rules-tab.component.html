Relationship Formula

A relationship is directional: how the source sees the target. Score = Values + Beliefs, then the stress composition and multipliers below, then manual bumps. The same score drives every relationship view, character compatibility, and the Defection Check. Defaults are provisional until the balancing pass.

Values (position on the triangle)

× closeness: +1 for identical positions anywhere (including the centre), −1 for opposite corners. Default {{ defaults.valueSimilarityScale }}
