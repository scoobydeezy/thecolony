### Incursion Trigger
The selected **OCC Engram** is activated for the first time inside the powered Engram Core's **full identity-comparison mode**.

The corrupted record contains first-person Memory whose false self-model remembers being someone. The Core is built to compare that unknown Memory against authentic candidates and determine which subject fits. At full comparison strength, the apparatus therefore supplies **Recognition** strongly enough for the corrupted Engram to become a Source and reconstruct corporeally.

The trigger is the mnemonic topology created by the full comparison lattice, not Darkwing's branch-specific relationships and not accidental misfiling.

### Reconstruction Condition
The corrupted Engram remains mounted inside the powered Core comparison lattice and has not been Stabilized by authentic Memory.

Vault Lockdown physically secures the Engram inside the Core. Lockdown is not itself a supernatural Ward and does not make the Source indestructible. If Darkwing Breaches the Source and destroys or otherwise renders the Engram incapable of carrying its Weight, resolve **Mnemonic Rupture** normally.

### Occlusion-Derived Memory
The Source was recorded from an **Occlusion**, not directly from the verified person whose identity the Occlusion claimed. The Engram therefore accurately preserves the Occlusion's subjective Memory while remaining an unreliable claim about the identity underneath it.

Its archival identifier carries the **-OCC** suffix. The exact selected record is determined by the five-match table in the owning encounter.
